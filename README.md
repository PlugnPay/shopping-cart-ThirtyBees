# PlugnPay Payment Modules for thirty bees

This repository contains PlugnPay payment integrations packaged by supported
thirty bees release.

## Available modules

- [thirty bees 1.7.x — PlugnPay Remote API](ThirtyBees_v1.7.x/README.md)
- [thirty bees 1.7.x — PlugnPay Smart Screens v2](ThirtyBees_v1.7.x/INSTALL_SS2.txt)

The Remote API module collects card details on the merchant storefront and
submits them server-to-server to PlugnPay. The Smart Screens v2 module
redirects customers to PlugnPay hosted pages for lower PCI scope.

## Support

The modules are provided AS IS. See the
[PlugnPay documentation](https://docs.plugnpay.com/) and the
[thirty bees documentation](https://docs.thirtybees.com/) for platform help.
