====================================================
PlugnPay Smart Screens v2 Module (Hosted Payments)
Payment Module for thirty bees v1.7.x — module v1.0.1
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

This module redirects customers to PlugnPay Smart Screens v2 hosted
billing pages (https://pay1.plugnpay.com/pay/). Your store does not
collect card data onsite.

Transactions are AUTHORIZATION-ONLY (pb_post_auth=no). Orders are
left Preparation/Pending. Capture, void, and refund are performed in
PlugnPay Merchant Admin — not from thirty bees.

There is no public demo gateway account. Use merchant-supplied
credentials from your PlugnPay account. HTTPS is required.
***************************

To Install:

1. Preferred: In Back Office → Modules and Services →
   "Upload a module", upload thirtybees_1.7.0_ss2_module.zip.

   Or unzip thirtybees_1.7.0_ss2_module.zip into your thirty bees
   modules directory so you have:
     modules/plugnpayss2/...

   From this repo's development tree that is:
     ThirtyBees_v1.7.x/src/modules/plugnpayss2/ → <shop>/modules/plugnpayss2/

2. In Back Office → Modules and Services, install/enable
   "PlugnPay Smart Screens v2".

3. Configure Gateway Account. Optionally enable database storage and
   debug logging. Select allowed currencies / countries under
   Payment preferences / module restrictions.

4. Place a test order using your merchant account / PlugnPay test
   procedures.

Requirements:

- thirty bees 1.7.0
- PHP 8.0 or later
- HTTPS enabled for the storefront
- PlugnPay gateway account username

No Remote Client Password is required for Smart Screens v2.
