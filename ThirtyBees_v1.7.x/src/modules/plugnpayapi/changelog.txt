PlugnPay Remote API for thirty bees

Version 1.0.5 - 2026-08-24
--------------------------------
- Matched Authorize.net AIM and official bankwire: hookPayment plus displayPayment, both return HTML strings.
- Wrapped payment template rendering so a Smarty error cannot HTTP 500 the whole payment step.
- Upgrade restores currency/country/carrier restriction rows that hide the module when missing.
- Checkout token is bound to the cart secure_key. Card form uses niara payment_module markup.

Version 1.0.4 - 2026-08-24
--------------------------------
- Removed displayPaymentEU so PHP 8 does not fatal when thirty bees concatenates payment hook output.
- Simplified expiry-year Smarty variables to scalar year codes.

Version 1.0.3 - 2026-08-24
--------------------------------
- Showed the card form on the payment step instead of hiding it until click.
- Stopped requiring detected HTTPS before listing the payment method.
- Registered displayPaymentEU and default currency/country/carrier restrictions.
- Loaded the checkout customer from the cart when context customer is empty.

Version 1.0.2 - 2026-08-24
--------------------------------
- Assigned Smarty variables on the module Smarty_Data object used by thirty bees 1.7.
- Rendered hook templates as payment.tpl / order_confirmation.tpl, matching core payment modules.
- Replaced deprecated Cart::getOrderShippingCost() with Cart::ONLY_SHIPPING.
- Passed the cart secure_key into validateOrder(), matching bankwire on thirty bees 1.7.
- Used PrestaShopLogger instead of the Logger alias.
- Returned an empty string from displayPayment when the method is unavailable (PHP 8 concatenation).

Version 1.0.1 - 2026-08-24
--------------------------------
- Registered the canonical displayPayment, paymentReturn, and displayHeader hooks.
- Added PrestaShop 1.6-style hook method aliases for thirty bees compatibility.
- Added an upgrade routine so existing installations receive the corrected hooks.
- Documented PHP 8.0 or later as the supported PHP version.

Version 1.0.0 - 2026-08-24
--------------------------------
- Initial thirty bees 1.7.x release.
- Added production Remote API authonly and authpostauth processing.
- Added onsite card validation, HTTPS gating, and checkout token validation.
- Added sanitized debug logging and transaction metadata recording.
- Added installation, PCI, troubleshooting, and manual test documentation.
